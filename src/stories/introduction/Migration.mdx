<I18nText

      <li>

        </ul>
      </li>
      <li>
        <b>Public exports</b>
        <ul>
          <li>New is effectively a superset of legacy root exports.</li>

        </ul>
      </li>
    </ul>
  }

## <I18nText en="Breaking / High-Risk Changes" zh="破坏性 / 高风险变更" />

- **DataTable**
  - Legacy: `react-data-table-component`
  - New: `@tanstack/react-table`
- **Tooltip**
  - Legacy: `react-tooltip`
  - New: Radix Tooltip-based implementation
- **JsonView**
  - Legacy: `react-json-view`
  - New: `@microlink/react-json-view`

## Styles
