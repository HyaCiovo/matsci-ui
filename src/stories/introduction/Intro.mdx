# mp-react18-components

This repository provides reusable React 18 UI components used by Materials Project surfaces.

Install:

`npm install @hyacinth/mp-react18-components`

Import styles once in your app entry:

`import '@hyacinth/mp-react18-components/style.css'`

If you are migrating from the legacy package, start with **Migration (mp-react vs mp-react18)** for a diff overview.

## Key Features

- Interactive crystal structures using threejs
- Input-linked periodic table for entering formulas and element lists
- Complete search interface for dynamically filtering data from a REST API
- A suite of components for fetching and rendering publications data in an easy and structured way
