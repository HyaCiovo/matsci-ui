# matsci-ui

This repository provides reusable React 18 UI components used by Materials Project surfaces. It is based on the legacy `mp-react-components` repository and modernizes the implementation for a React 18-first ecosystem.

Install:

`npm install @hyacinth/matsci-ui`

Import styles once in your app entry:

`import '@hyacinth/matsci-ui/style.css'`

If you are migrating from the legacy package, start with **Migration (mp-react → matsci-ui)** for a diff overview.

## Key Features

- Interactive crystal structures using threejs
- Input-linked periodic table for entering formulas and element lists
- Complete search interface for dynamically filtering data from a REST API
- A suite of components for fetching and rendering publications data in an easy and structured way
