# <I18nText en="matsci-ui" zh="matsci-ui" />

<I18nText
  en="`@hyacinth/matsci-ui` is a React component library for materials science products. It modernizes the legacy `mp-react-components` codebase into an npm-first, ESM-first, type-safe package with Storybook 10 documentation and Vitest-based tests."
  zh="`@hyacinth/matsci-ui` 是一个面向材料科学产品的 React 组件库。它将历史 `mp-react-components` 仓库收敛为 npm-first、ESM-first、类型安全的现代包，并以 Storybook 10 和 Vitest 作为文档与测试基线。"
/>

<I18nText

## <I18nText en="Quick Start" zh="快速开始" />

<I18nText
  en="Install the package, import the bundled stylesheet once, and then use named imports for the components you need."
  zh="安装依赖后，在应用入口只引入一次打包样式，然后按需导入所需组件即可。"
/>

```bash
npm install @hyacinth/matsci-ui
```

```tsx
import '@hyacinth/matsci-ui/style.css';
import { Modal, ModalContextProvider, ModalTrigger } from '@hyacinth/matsci-ui';

export function DemoModal() {
  return (
    <ModalContextProvider>
      <ModalTrigger>
        <button type="button">Open</button>
      </ModalTrigger>
      <Modal>
        <div className="box">Hello from matsci-ui</div>
      </Modal>
    </ModalContextProvider>
  );
}
```

## <I18nText en="Styling Status" zh="样式现状" />

<I18nText
  en="The stable styling path today is the bundled `@hyacinth/matsci-ui/style.css`, which still assumes the Bulma-oriented styling model. Files such as `src/theme/tokens.css` describe a direction of travel, but they should be treated as planning assets rather than as a stable theming API."
  zh="当前稳定可用的样式入口仍是打包后的 `@hyacinth/matsci-ui/style.css`，其内部依然建立在 Bulma 导向的样式体系上。像 `src/theme/tokens.css` 这样的文件更多是在描述未来方向，而不是已经稳定可用的主题 API。"
/>

## <I18nText en="Accessibility" zh="无障碍" />

<I18nText
  en={
    <ul>
      <li>Dialogs, tooltips, dropdowns, tabs, and checkboxes are built on Radix primitives.</li>
      <li>Search UI and table controls expose `aria-*` labels and keyboard-friendly interaction paths.</li>
      <li>Consumer-facing copy is usually customizable through `texts` objects or explicit label props.</li>
    </ul>
  }
  zh={
    <ul>
      <li>对话框、提示、下拉、Tabs、Checkbox 等基础交互基于 Radix primitives。</li>
      <li>Search UI 和表格控件提供 `aria-*` 文案与键盘友好的交互路径。</li>
      <li>面向用户的文案通常可以通过 `texts` 对象或显式 label props 覆盖。</li>
    </ul>
  }
/>
