# <I18nText en="matsci-ui" zh="matsci-ui" />

<I18nText
  en="This repository provides reusable React 18 UI components used by Materials Project surfaces. It is based on the legacy `mp-react-components` repository and modernizes the implementation for a React 18-first ecosystem."
  zh="这个仓库提供 Materials Project 相关产品所使用的一套可复用 React 18 UI 组件库。本仓库基于历史版本 `mp-react-components`，并将实现现代化以适配 React 18 生态。"
/>

## <I18nText en="Key Features" zh="主要特性" />

<I18nText
  en={
    <>
      <ul>
        <li>Interactive crystal structures using threejs</li>
        <li>Input-linked periodic table for entering formulas and element lists</li>
        <li>Complete search interface for dynamically filtering data from a REST API</li>
        <li>A suite of components for fetching and rendering publications data in an easy and structured way</li>
      </ul>
    </>
  }
  zh={
    <>
      <ul>
        <li>基于 threejs 的交互式晶体结构可视化</li>
        <li>与输入联动的周期表，用于输入化学式与元素列表</li>
        <li>完整的搜索界面，用于对 REST API 返回数据进行动态筛选</li>
        <li>一套用于获取并结构化展示出版物数据的组件</li>
      </ul>
    </>
  }
