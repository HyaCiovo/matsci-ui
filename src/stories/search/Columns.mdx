# <I18nText en="Columns" zh="列配置" />

<I18nText
  en="The `columns` prop defines which fields should be queried, how each field should be rendered, and which fields participate in sorting, visibility, or rich header behavior. The same shape is reused by `SearchUIContainer`, `DataTable`, and `DataBlock`."
  zh="`columns` 用来定义要查询哪些字段、每个字段如何渲染，以及哪些字段参与排序、显示控制或富头部展示。`SearchUIContainer`、`DataTable` 与 `DataBlock` 共享这一套结构。"
/>

<ArgTypes of={ColumnInterface} />

## <I18nText en="Example" zh="示例" />

```js
[
  {
    title: 'Material ID',
    selector: 'material_id',
    formatType: 'LINK',
    formatOptions: {
      baseUrl: '/materials/',
    },
    minWidth: '130px',
  },
  {
    title: 'Formula',
    selector: 'formula_pretty',
    formatType: 'FORMULA',
    minWidth: '130px',
  },
  {
    title: 'Energy Above Hull',
    selector: 'energy_above_hull',
    formatType: 'FIXED_DECIMAL',
    formatOptions: {
      decimals: 2,
      abbreviateNearZero: true,
    },
    units: 'meV/atom',
    conversionFactor: 1000,
    right: true,
  },
  {
    title: 'Predicted Stable',
    selector: 'is_stable',
    formatType: 'BOOLEAN',
    formatOptions: {
      truthyLabel: 'yes',
      falsyLabel: 'no',
    },
  },
];
```

## <I18nText en="Common Patterns" zh="常见模式" />

<I18nText
  en={
    <ul>
      <li>Use `selector` for plain field access such as `material_id` or nested access such as `symmetry.symbol`.</li>
      <li>Use `formatType` plus `formatOptions` when the cell needs domain-specific rendering.</li>
      <li>Use `render` only when built-in formats are insufficient and you need full control.</li>
      <li>Use `hidden`, `omit`, and `excludeFromColumnsSelector` to control presentation without losing query semantics.</li>
    </ul>
  }
  zh={
    <ul>
      <li>用 `selector` 指定普通字段访问，如 `material_id`，或嵌套字段访问，如 `symmetry.symbol`。</li>
      <li>当单元格需要领域格式化时，使用 `formatType` 与 `formatOptions`。</li>
      <li>只有在内置格式不足时再使用 `render`，以获得完全控制权。</li>
      <li>使用 `hidden`、`omit`、`excludeFromColumnsSelector` 控制展示层，而不破坏查询语义。</li>
    </ul>
  }
/>

## <I18nText en="Frequently Used Format Types" zh="常用格式类型" />

<I18nText
  en={
    <ul>
      <li><b>`FORMULA`</b>: render chemical formulas with domain-aware formatting</li>
      <li><b>`LINK`</b>: render labels as URLs or build URLs from `baseUrl`</li>
      <li><b>`FIXED_DECIMAL`</b>: round numeric values to a configured decimal count</li>
      <li><b>`SIGNIFICANT_FIGURES`</b>: keep scientific precision consistent across rows</li>
      <li><b>`BOOLEAN`</b> and <b>`BOOLEAN_CLASS`</b>: map boolean values to labels or icon classes</li>
      <li><b>`SPACEGROUP_SYMBOL`</b> and <b>`POINTGROUP`</b>: render crystallographic symbols with unicode-aware formatting</li>
    </ul>
  }
  zh={
    <ul>
      <li><b>`FORMULA`</b>：以化学式友好的方式渲染材料配方</li>
      <li><b>`LINK`</b>：直接渲染 URL，或基于 `baseUrl` 拼接跳转地址</li>
      <li><b>`FIXED_DECIMAL`</b>：按固定小数位数渲染数值</li>
      <li><b>`SIGNIFICANT_FIGURES`</b>：按有效数字保持科学数据的一致展示</li>
      <li><b>`BOOLEAN`</b> 与 <b>`BOOLEAN_CLASS`</b>：把布尔值映射为文案或图标 class</li>
      <li><b>`SPACEGROUP_SYMBOL`</b> 与 <b>`POINTGROUP`</b>：按晶体学语义渲染群符号</li>
    </ul>
  }
/>

## <I18nText en="Accessibility" zh="无障碍" />

<I18nText
  en={
    <ul>
      <li>Prefer explicit text labels over icon-only cell content.</li>
      <li>When you use `render`, keep links and buttons keyboard reachable and provide `aria-label` values when the visible text is ambiguous.</li>
      <li>Do not rely on color alone when a column communicates state.</li>
    </ul>
  }
  zh={
    <ul>
      <li>优先使用可读文本，而不是纯图标单元格。</li>
      <li>如果使用 `render` 自定义渲染，请保证链接和按钮可键盘聚焦，并在文案不够明确时补 `aria-label`。</li>
      <li>当列表达状态时，不要只依赖颜色差异。</li>
    </ul>
  }
/>

## <I18nText en="Performance" zh="性能" />

<I18nText
  en={
    <ul>
      <li>Keep `columns` reference-stable in app code to reduce unnecessary re-computation.</li>
      <li>Prefer built-in `formatType` handling over heavy custom `render` trees.</li>
      <li>Avoid rendering large nested React subtrees in every cell when server-side pagination is available.</li>
    </ul>
  }
  zh={
    <ul>
      <li>在业务代码中保持 `columns` 引用稳定，减少不必要的重复计算。</li>
      <li>能用内置 `formatType` 时，优先不要写过重的自定义 `render`。</li>
      <li>如果服务端分页可用，不要在每个单元格里渲染庞大的嵌套 React 子树。</li>
    </ul>
  }
/>
