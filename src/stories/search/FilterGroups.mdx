# <I18nText en="Filters" zh="筛选器" />

<I18nText
  en="`filterGroups` describes the structured filters that appear beside the result area. Each group contains one or more filters, and each filter maps user interaction to one or more query parameters."
  zh="`filterGroups` 用来描述结果区旁边出现的结构化筛选器。每个分组包含一个或多个 filter，而每个 filter 会把用户交互映射到一个或多个查询参数。"
/>

## <I18nText en="Example" zh="示例" />

```js
[
  {
    name: 'Composition',
    expanded: false,
    filters: [
      {
        name: 'Formula',
        params: ['formula'],
        isSearchBarField: true,
        tooltip: 'Find records by exact formula or wildcard formula',
        type: 'MATERIALS_INPUT',
        props: {
          type: 'formula',
          periodicTableMode: 'none',
        },
      },
      {
        name: 'Number of Elements',
        params: ['nelements_min', 'nelements_max'],
        type: 'SLIDER',
        props: {
          domain: [1, 20],
          step: 1,
        },
      },
    ],
  },
  {
    name: 'Thermodynamics',
    filters: [
      {
        name: 'Energy Above Hull',
        params: ['energy_above_hull_min', 'energy_above_hull_max'],
        units: 'eV/atom',
        type: 'SLIDER',
        props: {
          domain: [0, 1],
          step: 0.01,
        },
      },
    ],
  },
];
```

## <I18nText en="Supported Filter Types" zh="支持的筛选类型" />

<I18nText
  en={
    <ul>
      <li>`MATERIALS_INPUT`: chemistry-aware input for formulae, material IDs, chemical systems, and elements</li>
      <li>`SLIDER`: min/max value range mapped to two params</li>
      <li>`SELECT`: explicit option selection</li>
      <li>`THREE_STATE_BOOLEAN_SELECT`: true / false / unset state</li>
      <li>`CHECKBOX_LIST`: multi-select values serialized into a list-like query value</li>
      <li>`TEXT_INPUT`: free-form string entry</li>
      <li>`SELECT_SPACEGROUP_SYMBOL`, `SELECT_SPACEGROUP_NUMBER`, `SELECT_CRYSTAL_SYSTEM`, `SELECT_POINTGROUP`: domain-derived option sets</li>
    </ul>
  }
  zh={
    <ul>
      <li>`MATERIALS_INPUT`：面向化学式、材料 ID、化学系统和元素列表的领域输入控件</li>
      <li>`SLIDER`：映射到两个参数的最小值/最大值范围筛选</li>
      <li>`SELECT`：显式下拉选项选择</li>
      <li>`THREE_STATE_BOOLEAN_SELECT`：真 / 假 / 未设置三态选择</li>
      <li>`CHECKBOX_LIST`：多选值并序列化为列表式查询参数</li>
      <li>`TEXT_INPUT`：自由文本输入</li>
      <li>`SELECT_SPACEGROUP_SYMBOL`、`SELECT_SPACEGROUP_NUMBER`、`SELECT_CRYSTAL_SYSTEM`、`SELECT_POINTGROUP`：由领域常量派生选项</li>
    </ul>
  }
/>

## <I18nText en="Accessibility" zh="无障碍" />

<I18nText
  en={
    <ul>
      <li>Group headers expose disclosure semantics via `aria-expanded` and `aria-controls`.</li>
      <li>Tooltips should supplement, not replace, visible labels.</li>
      <li>When a filter drives a critical business rule, keep the label explicit and concise.</li>
    </ul>
  }
  zh={
    <ul>
      <li>分组标题通过 `aria-expanded` 与 `aria-controls` 暴露折叠/展开语义。</li>
      <li>tooltip 适合作为补充信息，而不应替代可见标签本身。</li>
      <li>当筛选器承载关键业务规则时，请保持标签明确且简洁。</li>
    </ul>
  }
/>

## <I18nText en="Performance" zh="性能" />

<I18nText
  en={
    <ul>
      <li>Keep filter configs static or memoized so the container can preserve internal state efficiently.</li>
      <li>Avoid large checkbox lists when the backend supports autocomplete or text search.</li>
      <li>Use `debounce` on the container when free-form filters are likely to trigger frequent requests.</li>
    </ul>
  }
  zh={
    <ul>
      <li>尽量让筛选配置保持静态或做 memo 化，方便容器稳定维护内部状态。</li>
      <li>如果后端支持自动完成或文本搜索，不要轻易堆叠非常长的复选列表。</li>
      <li>当自由输入筛选器可能频繁触发请求时，可在容器上设置 `debounce`。</li>
    </ul>
  }
/>
